# Blockchain Simulation

## Deskripsi
Blockchain Simulation adalah aplikasi simulasi blockchain sederhana berbasis Python dan Flask. Aplikasi ini dibuat untuk memahami cara kerja transaksi digital, proses mining, dan validasi blockchain.

## Fitur
- Mengirim coin antar pengguna.
- Menampilkan transaksi yang belum ditambang.
- Melakukan mining untuk membuat block baru.
- Memberikan reward kepada miner.
- Menampilkan hash dan previous hash.
- Memeriksa validitas blockchain.
- Mereset blockchain.

## Pengguna
- Alice
- Bob
- Charlie
- David
- Eve

Saldo awal Alice adalah 500 coin.

## Teknologi
- Python
- Flask
- HTML
- CSS
- SHA-256

## Cara Menjalankan
1. Install Python.
2. Install Flask dengan perintah `pip install flask`.
3. Buka folder proyek melalui CMD.
4. Jalankan `python app.py`.
5. Buka browser dan akses `http://127.0.0.1:5000`.

## Tujuan
Proyek ini dibuat sebagai media pembelajaran untuk memahami konsep dasar blockchain melalui simulasi transaksi dan mining.
